# Analyse RainLoop 1.17 : MailSo/Base et MailSo/Vendors face à wmail-go

Périmètre : `app/libraries/MailSo/Base/*` (Utils, HtmlUtils, Http, LinkFinder, Crypt, DateTimeHelper, Collection, ResourceRegistry, Validator, Loader, StreamWrappers, Enumerations, Exceptions) et `MailSo/Vendors/Net/IDNA2*.php` (survol).
Chemins Go relatifs à `/home/gdegoulet/Work/webmail_project/`. Les sources RainLoop ont été lues sans être copiées.

Constats d'ensemble (à lire avant les tableaux) :
- L'assainissement HTML de wmail-go (`internal/mailview/sanitize.go`) est une liste blanche bluemonday, bien plus stricte que `HtmlUtils::ClearHtml` (liste noire). Gains de sécurité réels, mais perte de fidélité visuelle (voir HtmlUtils ci-dessous : styles `display`/`float`/`background`, images de fond, `<form>`, attributs `background`/`bgcolor` du body, listes `type`/`start`).
- La conversion HTML vers texte (`mailview.HTMLToText`, utilisée pour la partie texte des envois HTML) ne reproduit pas `ConvertHtmlToPlain` : pas d'URL des liens, pas de puces, cellules de tableau collées.
- Un bug probable : dans `mailview.Parse`, une partie dont le jeu de caractères est inconnu de x/text est ignorée (`continue`, parse.go:156-158) alors que go-message renvoie quand même la partie lisible. Le texte du message disparaît silencieusement.
- Le texte brut n'applique pas `format=flowed` (DecodeFlowedFormat) : les courriels Thunderbird s'affichent avec des retours à la ligne durs.
- IDN/punycode : aucune gestion (`IdnToAscii`/`IdnToUtf8`) alors que RainLoop l'applique à l'identifiant, aux hôtes, aux adresses d'envoi et à l'affichage.

Légende verdicts : OK, PARTIEL, MANQUANT, SANS OBJET. Priorités : P1 (visible chaque jour), P2, P3.

## À AJOUTER (MANQUANT et PARTIEL, par priorité)

### P2
1. **Partie de message ignorée si charset inconnu** (`Parse`, `mailview/parse.go:156-158`) : ne pas faire `continue` ; traiter le corps brut (UTF-8 si valide, sinon windows-1252). Ajouter les alias `asci`/`us-asci` et un décodage de repli `utf-7`. Évite les messages vides silencieux. (`ConvertEncoding`, `NormalizeCharset`)
2. **`format=flowed` / `delsp`** pour le texte brut (`DecodeFlowedFormat`) : recoller les lignes terminées par une espace avant `TextToHTML`. Les courriels de Thunderbird s'affichent sinon avec des retours à la ligne durs.
3. **Texte brut : préserver les espaces** : `white-space:pre-wrap` (ou nbsp pour doubles espaces/tabulations) dans le mode texte (`bodyDocHead`, `web/mail.go:998`), comme `ConvertPlainToHtml`.
4. **Liens dans le texte brut** (`findLinks`/`findMails`/`UseDefaultWrappers`) : ajouter `www.`, `ftp/git/svn`, adresses e-mail (`mailto:`), équilibre des parenthèses finales (`text.go:38-50`).
5. **`HTMLToText` fidèle à `ConvertHtmlToPlain`** (partie texte d'un envoi HTML) : « texte (url) » pour les liens, puces `* `, séparateur de cellules, `hr`.
6. **Contenu d'un `<form>` conservé** (`sanitize.go:89-90`) : sortir `form` et `button` de `SkipElementsContent` ; sinon les messages entièrement dans un `<form>` apparaissent vides.
7. **Styles CSS élargis** (`ClearStyle`) : `display` (≠ none), `float`, `clear`, `background` (sans url), `font`, `border-radius`, `box-shadow`, `text-shadow`, `overflow`, `opacity`, `list-style`, `word-break`, `box-sizing` ; et `background`/`background-image` via `cid:`, `data:image`, ou image distante gérée comme `rewriteImage`.
8. **Fond et couleurs du `<body>`/`<html>`** (`GetTextFromDom`/`ClearBodyAndHtmlTag`) : reporter `bgcolor`, `text`, `link`, `style`, `dir`, `lang` du body sur un div englobant (et `background` des tables/cellules).
9. **Normalisation du charset selon le contenu** (`NormalizeCharsetByValue`) : si le corps est de l'UTF-8 valide malgré un charset déclaré latin-1, ne pas convertir.
10. **Noms de pièces jointes RFC 2047 entre guillemets** (hors Base mais lié à `DecodeHeaderValue`) : `parse.go:172,201-203` utilise `Filename()` / `params["name"]` sans décodage ; ajouter `mime.WordDecoder{CharsetReader: message.CharsetReader}.DecodeHeader(name)` quand le nom commence par `=?`. (Gmail et d'anciens clients envoient `name="=?UTF-8?B?…?="`.)

### P3
12. **IDN/punycode** (`IdnToAscii`/`IdnToUtf8`/`idn`/IDNA2) : `golang.org/x/net/idna` pour les destinataires à domaine unicode (`compose.ParseList`), les hôtes saisis (`mailconn.ValidHost`) et l'affichage (`addrList`).
13. **Cache HTTP des fichiers statiques** (`ServerUseCache`) : ETag/Cache-Control pour `/static/` et `/themes/`.
14. **Détection des pixels espions** étendue au `style` et à la hauteur seule (`isTracker`, `sanitize.go:219-233`).
15. **Résolution des images `Content-Location`** (HTML/MHT) comme des `cid:`.
16. **Attributs de présentation** (`ol/ul type/start`, `li value`, `td nowrap`, `img hspace/vspace/border`, `hr width`, liens `ftp:`).
17. **`ClearFastTags`** : supprimer les `<p></p>` vides (espacement Outlook).
18. **`MimeContentType`** : repli `mime.TypeByExtension` pour les pièces déposées sans type utile.
19. **`ClearFileName`** : retirer aussi `: * ? < > | "` des noms téléchargés (`safeFileName`, `web/mail.go:1200`).
20. **Icône par catégorie de pièce jointe** (`ContentTypeType` : archive, doc, pdf, image) en CSS.
21. **Avatar local** (initiales colorées) à la place de Gravatar, sans requête externe.

23. **`PrepareHTML` : conserver les images distantes d'un transfert** (option) au lieu de toutes les retirer.
