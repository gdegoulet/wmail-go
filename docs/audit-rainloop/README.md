# Analyses de RainLoop 1.17 (2026-10-23/24)

Rapports produits en relisant le code de RainLoop (lecture seule) et en le comparant à wmail-go :

- `audit_*.md` : première relecture par thème (liste, lecture, réglages, composition, contacts, serveur).
- `fn_*.md` : seconde relecture, **fonction par fonction** (PHP : Actions, MailSo, carnet d'adresses, divers ; JavaScript :
  `app.js` en cinq tranches ; gabarits HTML ; feuille de style ; fichiers de langue). Chaque rapport finit par une section
  « À AJOUTER » classée par priorité (P1 quotidien, P2, P3).

Les plugins de l'utilisateur (`ics-preview`, `add-x-originating-ip-header`) ont été relus à la main : voir CAHIER_DES_CHARGES.md,
chapitre 15. Ces rapports décrivent des comportements ; aucun code ni texte de RainLoop n'y est recopié.
