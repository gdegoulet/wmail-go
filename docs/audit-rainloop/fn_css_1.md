# Analyse RainLoop 1.17 `static/css/app.css` lignes 1 à 6000 (feuille de style) contre wmail-go

Fichiers lus en entier : `/Work/webmail_project/rainloop/1.17.0/static/css/app.css` L1-6000 (les ~1700 premières lignes de normalize/jQuery UI/police d'icônes lues en détail, le reste via une version compactée sans préfixes `-webkit-/-moz-/-o-/-ms-` ni filtres IE ; les lignes minifiées 1494, 2063, 2064, 2065 et les data-URI base64 de pikaday ont été lues partiellement : sélecteurs et règles clés seulement). Côté wmail-go : `internal/web/static/app.css` (67 l.), `mail.css` (492 l.), `themes/rainloop/theme.css` (73 l.), `print.css`, `noscript.css`, `base.html` (sprite d'icônes), `home.html`, `preview.js`, `chips.js`, `folders.js`. Couleurs DarkShine : `scratchpad/ds/out.css` (284 l., lu en entier).

## Constat préalable important

Les lignes 1-6000 de `app.css` ne contiennent PAS les composants propres à RainLoop (connexion, dossiers, liste, barres d'outils, message, composition, popups, réglages). Elles contiennent uniquement des bibliothèques embarquées : normalize.css (1-353), jQuery UI 1.10.3 (355-993), police d'icônes « rainloop » (995-1385), nanoScroller (1388-1492), letterfx (1494), inputosaurus (1495-1557), drapeaux (1559-1616), opentip (1618-1822), pikaday (1824-2061), lightGallery (2063-2064), progress.js (2065-2105), Bootstrap 2.3 complet (2107-5928) et quelques surcharges RainLoop (5930-5998 : `body`, `label`, `.close-custom`, `.minimize-custom`, `.legend`, `.input-append`). Les composants (`.g-ui-menu`, `.b-folders`, `.messageList`, `.b-compose`, popups, `.inputosaurus-container` effectif...) se trouvent après la ligne 6000 (tranche suivante). J'ai juste vérifié par grep que certaines règles Bootstrap de cette tranche y sont surchargées (ex. `.g-ui-menu` L6633, `.inputosaurus-container` L6323, `.btn-toolbar` L6098, `.btn.btn-success` L6095) : quand c'est le cas je le signale et je renvoie à la tranche 2 pour le verdict final. Le thème DarkShine (`out.css`) ne modifie rien de cette tranche : il ne définit que `.thm-*`, `.g-ui-menu`, `.thm-folders`, `.thm-settings-menu`, `.thm-login*`, `.thm-message-list-*-toolbar`, `html.glass` (hors tranche, déjà vus).

Les verdicts portent sur le RENDU VISIBLE que ces règles produisent dans l'UI RainLoop (leurs classes sont utilisées par les templates : `alert` 29 fois, `modal-header` 22, `form-horizontal` 49, `control-group` 142, `btn-group` 44, `btn-toolbar` 10, `btn-danger` 11, `icon-spinner` 58, `icon-ok` 22, `icon-remove` 22, relevés par grep dans `app/templates` et `static/js/app.js`).

Conversion : wmail-go est en rem sur base 14 px comme RainLoop (`app.css:3`), donc 1 rem = 14 px.
