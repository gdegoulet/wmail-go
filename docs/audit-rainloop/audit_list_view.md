# Audit fonctionnel RainLoop 1.17.0 : liste des messages et lecture d'un message

Périmètre : `rainloop/1.17.0` (lecture seule). Aucun dossier `data/` lu, aucun code exécuté ni recopié.
Ce document décrit uniquement ce que fait RainLoop. Il ne propose aucune implémentation.

## Conventions de référence

- `app.js:NNN` = `static/js/app.js` ligne NNN (fichier unique non minifié, bundle webpack).
- `Actions.php:NNN` = `app/libraries/RainLoop/Actions.php`.
- `MailClient.php:NNN` = `app/libraries/MailSo/Mail/MailClient.php`.
- `ServiceActions.php:NNN` = `app/libraries/RainLoop/ServiceActions.php`.
- `HtmlUtils.php:NNN` = `app/libraries/MailSo/Base/HtmlUtils.php`.
- Gabarits dans `app/templates/Views/User/` : `MailMessageList.html`, `MailMessageListItem.html`, `MailMessageListItemNoPreviewPane.html`, `MailMessageView.html`, `MailFolderList.html`, `MailFolderListItem.html`, `MailFolderListSystemItem.html`, `PopupsAdvancedSearch.html`, `PopupsFolderClear.html`. Aide clavier : `app/templates/Views/Common/PopupsKeyboardShortcutsHelp.html`. Pagination : `app/templates/Views/Common/Pagenator.html`.
- Libellés : `app/localization/webmail/fr_FR.yml` (le français est très incomplet pour `MESSAGE_LIST` : seule la clé `BUTTON_RELOAD` est traduite, le reste retombe sur l'anglais `_source.en.yml`).
- Capacités (`Capa`) = interrupteurs serveur par domaine/compte (`Config/Application.php:242-257`, `Actions.php:8117+`). Elles masquent ou désactivent des fonctions entières (voir thème U).
- Convention de lecture : « (réglage : X) » = option utilisateur de Paramètres > Général ; « (capa : X) » = capacité serveur ; « (config : labs.x) » = clé `application.ini`.

## 1. Navigation, routage, état de la boîte

1. F-LV-01 : Routage par fragment d'URL — la boîte courante, la page, la recherche et le fil sont portés par le hash `#/mailbox/<dossier>[~<uidFil>]/p<page>/<recherche>` ; l'URL est encodée par `encodeURI`. Un lien fonctionne comme signet/partage de vue. Cas limite : une page < 1 est ramenée à 1 ; hash vide = INBOX page 1 — `app.js:6564-6597`, `app.js:33902-33937`.
2. F-LV-02 : Chargement de la liste au changement de route — `onRoute` retrouve le dossier via le hash, positionne dossier courant, page, recherche, fil, puis appelle `reloadMessageList()`. Si le hash ne correspond à aucun dossier connu, rien ne se passe — `app.js:33832-33847`.
3. F-LV-03 : Écran "mailbox" démarre avec focus sur la liste — `onShow` remet le focus à `None` puis `MessageList`, force le panneau gauche replié en mobile, et masque le panneau dossiers (type `short` ou `none`) si la capacité Folders est absente — `app.js:33809-33823`.
4. F-LV-04 : Titre de l'onglet avec compteur de non lus — titre = `(N) email - Boîte mail` (N = non lus de la boîte de réception, omis si 0), complété du titre produit `Title` de l'admin. Cas limite : si un filtre permanent IMAP est configuré (`listPermanentFiltered`), le compteur est forcé à 0 — `app.js:33794-33803`, `app.js:23354-23363`, `Actions.php:1480`.
5. F-LV-05 : Le compteur de non lus d'INBOX alimente aussi le compte actif dans la liste des comptes — événement `mailbox.inbox-unread-count` (déclenché par la mise à jour de `messageCountUnread` du dossier INBOX) met à jour `foldersInboxUnreadCount` et `item.count` du compte courant — `app.js:33868-33879`, `app.js:32650-32654`.
6. F-LV-06 : Pré-chauffage de la fenêtre de composition — 500 ms après le démarrage de l'écran, la popup Compose est instanciée à l'avance — `app.js:33864-33866`.
7. F-LV-07 : Séparateur redimensionnable liste / aperçu / dossiers — poignées jQuery UI : hauteur liste (disposition horizontale, min 200, max 500) et largeur liste/dossiers (disposition verticale), tailles mémorisées en stockage client (clés `MessageListSize`, `FolderListSize`). Désactivé en mobile — `app.js:29269-29437`, `app.js:33886-33891`.
8. F-LV-08 : Clic hors des dossiers annule le mode "déplacer" — un clic dans `#rl-right` remet `moveAction` à faux — `app.js:33893-33895`.
9. F-LV-09 : Rechargement forcé si l'application est mise à jour — au réveil de l'onglet (`$.wakeUp`, 60 min) : si le timestamp client a changé ou si `jsVersion` côté serveur ne correspond plus, la page est rechargée (dans l'iframe parente si `inIframe`) — `app.js:28499-28513`.
